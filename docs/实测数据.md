## 阶段 8：零拷贝直扫

| 方案 | 每帧合成 | 帧率 |
|---|---|---|
| 合成（PLANE→FB→KMS） | 4.74 ms | 119.9 |
| 单次拷贝（PLANE→KMS） | 2.55 ms | 120.0 |
| **零拷贝（GBM dmabuf，生产端直写）** | **0.000 ms** | **120.0** |

关键：NVIDIA PRIME 导出的 dumb buffer 只允许只读 mmap（RW 返回 EACCES）；
GBM（`nvidia-drm_gbm.so`）缓冲可 RW mmap，dmabuf fd 可经 `SCM_RIGHTS` 传递。
3 个扫描缓冲 + `seq/ack` 3 深度握手。

## 阶段 9：NV12 硬解直扫（视频最优解）

| 路径 | 每帧成本 | 帧率 | 漏拍 |
|---|---|---|---|
| 合成 RGB | 4.74 ms | 119.9 | 0 |
| 单次拷贝 RGB | 2.55 ms | 120.0 | 0 |
| 零拷贝 RGB | 合成器 0.000 ms | 120.0 | 0 |
| **NV12 主平面 flip** | **填充 1.07 ms** | **120.1** | **0** |

- GBM NV12：2 plane，stride 2048，UV offset 2228224，modifier=LINEAR
- `gbm_bo_map` 对 NV12 返回 ENOSYS；dmabuf fd 可 RW mmap
- 每帧只写 3.1 MB（Y+UV）vs RGB 8 MB；120 Hz 下约 373 MB/s
- overlay plane 亦可 NV12；BT.709 需设 `COLOR_ENCODING=BT709`、`COLOR_RANGE=Limited`

## 阶段 13：tty2 桌面复刻 + 脏区更新 / 3 秒静止定格

场景 `assets/tty2desktop.wire`：9 surface / 53 段文字，复刻顶栏、SYSTEM/SPEC 面板、
dock、终端、Firefox、QQ、Cherry Studio。字体改为 Unifont `.hex` 直接烘焙：
7923 字形 / 329.5 KB，覆盖完整 GB2312。

### 机制

- 首帧 raster 后保存整张 FB 到 `CLEAN`
- 游标移动时只还原/重画旧、新两个 14×20 小矩形，且只同步这两个矩形
- 3 秒无变化 → 完全停止 page flip（定格）；有变化立即恢复
- `--mouse` 自动找带 `REL_X`/`REL_Y` 的 evdev（本机 Logitech G402 → `event3`）

### 实测

| 模式 | 结果 |
|---|---|
| 脚本游标 23 s | **1440 次更新，活动 120.0 Hz，0.0170 ms/次，脏区 0.0270% 全屏，2 次准确 3.0 s 定格** |
| 真实鼠标 6 s | 469 次更新（0.0245 ms/次），`event3` 输入正常 |
| 鼠标静止探测 | 4 秒内 REL 事件 0 条（无传感器抖动） |

说明：鼠标模式下“松手 3 秒定格”的整机运行验证因操作失误触发 sudo PAM 锁定
（10 分钟）而中断；定格路径本身已在脚本模式完整验证，且静止时 evdev 确实无事件。

## 安全事件与护栏

一次 B 站无限流测试中，`nv12_ui` 被 SIGKILL 时仍持有 DRM master，
CRTC 停留在其缓冲上，切回 tty1 后 sway 输出失效，只能重启。
此后所有 KMS 操作强制走 `run-safe.sh`：

1. 任何碰 `/dev/dri` 的程序一律经 `run-safe.sh`
2. 网络/解码先做有界下载，不在 tty 上跑无限流
3. 绝不 SIGKILL 持有 DRM master 的进程；先 `chvt 1` 释放，再杀
4. 每次结束验证 sway 输出 `active=true`
