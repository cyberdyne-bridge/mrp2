## 重新编译（示例）

```bash
cd ladder
cc -O2 -I/usr/include/libdrm -o bin/mrpd_kms  src/mrpd_kms.c  -ldrm -lgbm
cc -O2 -I/usr/include/libdrm -o bin/nv12_play  src/nv12_play.c  -ldrm -lgbm -lpthread
cc -O2 -I/usr/include/libdrm -o bin/shmscan_server src/shmscan_server.c -ldrm -lgbm
cc -O2 -I/usr/include/libdrm -o bin/kms_fast  src/kms_fast.c  -ldrm
```

依赖：`gcc`、`libdrm`（头文件在 `/usr/include/libdrm`）、`libgbm`、`ffmpeg`（真内容播放）、
`yt-dlp`（B 站，可选）。

## 重新生成资源

```bash
# 场景（需要 protocol/ 里的 proto.py）
cd protocol && PYTHONPATH=. python3 ../ladder/src/gen_tty2_desktop.py \
    ../ladder/assets/tty2desktop.wire

python3 ladder/src/bake_hex.py ladder/assets/font16.rom
```

## 运行（关键：安全护栏）

**任何碰 `/dev/dri` 的程序都必须经 `run-safe.sh`**：

```bash
cd ladder
sudo ./run-safe.sh 40 ./bin/mrpd_kms ./assets/tty2desktop.wire 0 120 \
    --font ./assets/font16.rom                      # 普通渲染
sudo ./tty2-desktop.sh mouse 120                    # 桌面复刻 + 鼠标/定格
sudo ./tty2-desktop.sh scripted 23                  # 自动示范
```

`run-safe.sh` 提供：硬超时、`setsid` 进程组终止、SIGTERM 优先、
必要时先 `chvt 1` 再 SIGKILL、结束后轮询验证 sway 输出恢复。

## 已知限制

- 协议本身没有边框、阴影、圆角、透明度渐变等装饰属性；窗口是平色矩形 + 标题条。
- MRP2 是系统级渲染协议，不适合作为 sway 的 Wayland 客户端协议；
  真实 KMS 输出需要独立 VT（tty2）或第二块 GPU/显示器。
- 阶段 13 的鼠标“静止 3 秒定格”逻辑与脚本模式已验证；
  鼠标模式整机定格测试因 sudo PAM 临时锁定中断，未完成最终确认。
